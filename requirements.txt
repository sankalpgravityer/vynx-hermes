# PINNED, and not to the latest on purpose.
#
# onnxruntime 1.29.0 fails to load on Windows 10 with only the VC++ 2015-2019
# redistributable (14.29) installed: `WinError 1114, A dynamic link library (DLL)
# initialization routine failed`, raised by onnxruntime.dll itself before Python
# is involved. Newer builds want the 2015-2022 redistributable (14.40+). 1.20.1
# is the newest release that loads against 14.29 and is the first with cp313
# wheels, so it is the one version that covers both.
#
# Linux is unaffected — any 1.2x works there. Raise this pin once every machine
# that runs Hermes has the 2022 redistributable, and note that accuracy is
# unchanged either way: same ONNX models, same operators.
onnxruntime==1.20.1
